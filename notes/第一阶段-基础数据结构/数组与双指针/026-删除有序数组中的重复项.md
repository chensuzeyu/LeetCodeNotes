# 26. 删除有序数组中的重复项

- 链接：https://leetcode.cn/problems/remove-duplicates-from-sorted-array/
- 难度：🟢 简单
- 专题：数组 / 双指针
- **语言：Python 3**（本仓库 Hot 100 笔记与示例代码统一使用 Python）
- 完成日期：（填）

## 题意理解

`nums` **非递减**（有序允许相等）。要求**原地**删除重复元素，使每种数值最多出现一次，并返回**新长度** `k`。`nums` 前 `k` 个位置应为去重后的结果，后面是什么通常不关心。

## 思路（多解法）

### 思路 A：快慢指针（同向双指针）——推荐

- `slow`：下一格「唯一元素该写在哪里」
- `fast`：从左到右扫描

规则：`fast` 遇到的数若与 `slow-1` 不同（或 `slow==0`），则写入 `nums[slow]` 并 `slow += 1`。因数组有序，相等元素必连续，这样天然每种值只留第一个。

### 思路 B：慢指针语义换成「当前保留的末尾值」

维护 `write` 与上一个写入的值 `last`（或直接比较 `nums[write-1]`），逻辑与 A 等价，只是变量命名不同。

### 思路 C：统计 + 新开数组（不符合「原地」训练目标）

遍历计数 unique 写入新列表，再拷回 `nums`。空间 O(n)，笔试/工程里可以，但本题考察原地。

### 思路 D：二分思想？不必要

有序提示容易想到二分，但删除重复只需线性扫描，无需二分。

## 核心代码（Python 3）

### A. 快慢指针

```python
def removeDuplicates(nums: list[int]) -> int:
    if not nums:
        return 0
    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow - 1]:
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

等价写法：先令 `slow = 0`，遇到「新值」时 `slow += 1` 再赋值（注意第一个元素总是保留）。

### B. 使用 `slow` 表示「已写长度」的另一种常见写法

```python
def removeDuplicates(nums: list[int]) -> int:
    k = 0
    for x in nums:
        if k == 0 or x != nums[k - 1]:
            nums[k] = x
            k += 1
    return k
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素访问常数次。
- 空间复杂度：O(1)，除若干整型指针外不用额外线性空间。

## 易错点 / 收获

- 题目要返回的是**新长度**，OJ 会根据长度检查前缀。
- `slow` 与 `fast` 的初始值、比较对象是 `nums[slow-1]` 还是 `nums[fast-1]` 要想清楚，避免 off-by-one。
- **有序**是算法成立前提；无序数组不能这么玩。
