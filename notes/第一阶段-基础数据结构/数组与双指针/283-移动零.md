### 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下 **原地** 对数组进行操作。

### 示例 1

**输入:** `nums = [0,1,0,3,12]`  
**输出:** `[1,3,12,0,0]`

### 示例 2

**输入:** `nums = [0]`  
**输出:** `[0]`

### 提示

- `1 <= nums.length <= 10⁴`
- `-2³¹ <= nums[i] <= 2³¹ - 1`

### 进阶

你能尽量减少完成的操作次数吗？

## 题意理解

给定数组 `nums`，把所有 **0** 移到末尾，**非零元素保持原有相对顺序**。必须 **原地** 操作（通常要求 O(1) 额外空间）。

## 思路（多解法）

### 思路 A：双指针「填坑」——推荐

用 `insert_pos` 表示下一个非零元素应放的位置。遍历 `i`：若 `nums[i] != 0`，则把它写到 `insert_pos`，`insert_pos += 1`。扫完后，把 `[insert_pos, n)` 全部置 0。

- 本质是两趟：先压缩非零，再尾部填零；相对顺序由从左到右写入保证。

### 思路 B：快慢指针交换（单趟）

`slow` 指向下一个该放非零的位置，`fast` 扫描；当 `nums[fast] != 0` 时，交换 `slow` 与 `fast`，`slow++`。

- 与 A 等价思想，通过交换在「单趟」内完成（0 会被逐步换到后面）。

### 思路 C：开新数组

过滤非零再后面补零，拷回 `nums`。需要 O(n) 辅助空间，适合先想清楚逻辑再改成原地。

### 思路 D：「滚雪球」/ 连续交换

遇到非零就把连续的一段交换到前面……与 B 同类，理解一种即可。

## 核心代码（Python 3）

### A. 先压缩再填零

```python
def moveZeroes(nums: list[int]) -> None:
    k = 0
    for x in nums:
        if x != 0:
            nums[k] = x
            k += 1
    for i in range(k, len(nums)):
        nums[i] = 0
```

### B. 交换版

```python
def moveZeroes_swap(nums: list[int]) -> None:
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

## 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)（方案 A、B）；开数组方案为 O(n)。

## 易错点 / 收获

- 题目强调**相对顺序**，不要用「把所有 0 换到最后」但破坏中间顺序的错误策略（例如只对 0 做无脑冒泡而不保持非零顺序）。
- **交换版**里，`slow` 左侧及 slow 位置最终都是非零（或说 slow 指向下一个待填非零位），注意循环不变量。
- 与 **27 移除元素**、**26 去重** 同为「双指针改写数组前缀」家族，可对比记忆。
