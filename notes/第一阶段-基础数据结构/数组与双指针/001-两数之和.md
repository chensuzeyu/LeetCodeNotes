### 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

### 示例 1

**输入：** `nums = [2,7,11,15]`, `target = 9`  
**输出：** `[0,1]`  
**解释：** 因为 `nums[0] + nums[1] == 9` ，返回 `[0, 1]` 。

### 示例 2

**输入：** `nums = [3,2,4]`, `target = 6`  
**输出：** `[1,2]`

### 示例 3

**输入：** `nums = [3,3]`, `target = 6`  
**输出：** `[0,1]`

### 提示

- `2 <= nums.length <= 10⁴`
- `-10⁹ <= nums[i] <= 10⁹`
- `-10⁹ <= target <= 10⁹`
- 只会存在一个有效答案

### 进阶

你可以想出一个时间复杂度小于 `O(n²)` 的算法吗？

## 题意理解

给定整数数组 `nums` 和目标值 `target`，找出**两个不同下标** `i`、`j`，使得 `nums[i] + nums[j] == target`，返回 `[i, j]`。题目保证有且仅有一组解。

## 思路（多解法）

### 思路 A：哈希表「见过谁」——推荐

一边遍历，一边把「值 → 下标」放进哈希表。对当前 `x = nums[i]`，查表里是否存在 `target - x`；若存在则配对成功。

- 为什么不先全放表里再搜？可以，但一边扫一边建表更自然，且避免同一元素用两次的细节处理。

### 思路 B：暴力枚举

两层循环枚举所有 `(i, j)`（`i < j`），判断 `nums[i] + nums[j] == target`。

- 适合理解题意与对拍，面试上只作为下界说明。

### 思路 C：排序 + 双指针（需还原下标）

将 `(值, 原下标)` 排序后，左右指针向中间收拢找和为 `target` 的一对。

- 时间多一个排序因子；且要处理**值相同但下标不同**的情况，实现啰嗦。本题更宜哈希。

### 思路 D：补全认知 —— 数组极小时

若 `n` 很小（例如 ≤ 8），位掩码枚举子集没有优势；仍推荐哈希。若约束是**有序数组**，则双指针 O(n) 更优（见 Hot 路线里的 167 题）。

## 核心代码（Python 3）

### A. 哈希表

```python
def twoSum(nums: list[int], target: int) -> list[int]:
    seen = {}  # 值 -> 下标
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []  # 题目保证有解则不会走到这里
```

### 预期输入和输出（同一思路可复用）

#### 用例 A
```text
输入: nums = [2,7,11,15], target = 9
输出: [0,1]
过程:
1. seen = {}
2. i=0, x=2, need=7, seen里没有 -> seen[2]=0
3. i=1, x=7, need=2, seen[2] 存在 -> 返回 [seen[2], 1] => [0,1]
```

#### 用例 B
```text
输入: nums = [3,2,4], target = 6
输出: [1,2]
过程:
1. i=0, x=3 -> seen = {3:0}
2. i=1, x=2 -> seen = {3:0,2:1}
3. i=2, x=4, need=2, seen[2] 存在 -> 返回 [seen[2],2] => [1,2]
```

#### 关键语法（该题专用）

```python
seen = {}            # dict：key->value，不是 list
seen[2] = 0          # 写入 key=2 的值 0
2 in seen            # 判断 key 是否存在
seen[2]              # 按 key 读取值 -> 0
seen.get(100, -1)    # 安全读取，不存在返回 -1
seen.pop(2, None)    # 安全删除 key=2，返回对应 value

arr = []             # list
arr.append(2)        # 追加值
arr[0]               # 按下标读取
```

`return [seen[need], i]` 的两层含义：
- `seen[need]`：dict 按 key 取值，拿到“配对数的下标”。
- 外层 `[...]`：创建返回列表。
- `seen` 在遍历中会随 `seen[x] = i` 增长到最多 `len(nums)` 个键。

相关基础复习可对照：`python-core-quickref/leetcode/02-containers.md`

### B. 暴力

```python
def twoSum_bruteforce(nums: list[int], target: int) -> list[int]:
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 哈希表 | O(n) | O(n) |
| 暴力 | O(n²) | O(1) |
| 排序 + 双指针 | O(n log n) | O(n) 或 O(log n)（排序栈空间） |

## 易错点 / 收获

- **先查用表再写入当前元素**，避免同一个下标被用两次。
- 无序数组找「配对和」首选哈希；**有序**再考虑双指针。
