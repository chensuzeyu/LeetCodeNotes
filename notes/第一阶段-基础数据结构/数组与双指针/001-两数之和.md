# 1. 两数之和

- 链接：https://leetcode.cn/problems/two-sum/
- 难度：🟢 简单
- 专题：数组 / 哈希表
- **语言：Python 3**（本仓库 Hot 100 笔记与示例代码统一使用 Python）
- 完成日期：（填）

## 题意理解

给定整数数组 `nums` 和目标值 `target`，找出**两个不同下标** `i`、`j`，使得 `nums[i] + nums[j] == target`，返回 `[i, j]`。题目保证有且仅有一组解。

## 思路（多解法）

### 思路 A：哈希表「见过谁」——推荐

一边遍历，一边把「值 → 下标」放进哈希表。对当前 `x = nums[i]`，查表里是否存在 `target - x`；若存在则配对成功。

- 为什么不先全放表里再搜？可以，但一边扫一边建表更自然，且避免同一元素用两次的细节处理。

### 思路 B：暴力枚举

两层循环枚举所有 `(i, j)`（`i < j`），判断 `nums[i] + nums[j] == target`。

- 适合理解题意与对拍，面试上只作为下界说明。

### 思路 C：排序 + 双指针（需还原下标）

将 `(值, 原下标)` 排序后，左右指针向中间收拢找和为 `target` 的一对。

- 时间多一个排序因子；且要处理**值相同但下标不同**的情况，实现啰嗦。本题更宜哈希。

### 思路 D：补全认知 —— 数组极小时

若 `n` 很小（例如 ≤ 8），位掩码枚举子集没有优势；仍推荐哈希。若约束是**有序数组**，则双指针 O(n) 更优（见 Hot 路线里的 167 题）。

## 核心代码（Python 3）

### A. 哈希表

```python
def twoSum(nums: list[int], target: int) -> list[int]:
    seen = {}  # 值 -> 下标
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []  # 题目保证有解则不会走到这里
```

### B. 暴力

```python
def twoSum_bruteforce(nums: list[int], target: int) -> list[int]:
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 哈希表 | O(n) | O(n) |
| 暴力 | O(n²) | O(1) |
| 排序 + 双指针 | O(n log n) | O(n) 或 O(log n)（排序栈空间） |

## 易错点 / 收获

- **先查用表再写入当前元素**，避免同一个下标被用两次。
- 无序数组找「配对和」首选哈希；**有序**再考虑双指针。
